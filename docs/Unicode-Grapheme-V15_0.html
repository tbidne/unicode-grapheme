textWidth :: Text -> Int Source #

Splits the text into grapheme clusters and counts each cluster width.

Examples

Expand
>>> textWidth "abc"

>>> -- U+004F U+0308
>>> textWidth "Ö"

>>> -- 🧑‍🌾
>>> textWidth "\x1F9D1\x200D\x1F33E"
